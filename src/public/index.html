📱 iOS Shortcuts API

Use these endpoints with iOS Shortcuts:

1. Create a download job:

POST /api/jobs
Content-Type: application/json
X-Auth-Token: your-token-here

{
  "url": "https://www.youtube.com/watch?v=..."
}

2. Wait for completion (recommended for Shortcuts):

GET /api/jobs/{jobId}/wait?token=your-token-here

Returns the download URL when ready

3. Check status manually:

GET /api/jobs/{jobId}?token=your-token-here

💡 Tip: The /wait endpoint polls for completion automatically, making it perfect for iOS Shortcuts (waits up to 5 minutes).

🔐 Authentication: Include your token as a query parameter (?token=...) or in the X-Auth-Token header. For downloads in Safari, use the query parameter method.
